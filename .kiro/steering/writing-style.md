# Writing style (humanizer rules)

Applies to everything a person will read: README, KIRO_USAGE.md, DEMO_SCRIPT.md, SUBMISSION.md, the Devpost description, UI copy, operator persona lines, code comments and commit messages. The submission must read like Clynton wrote it, not like a chatbot.

## Hard rules

- No em dashes or en dashes anywhere. Use a comma, colon, full stop or brackets.
- No chatbot leftovers: no "Great question", "Certainly", "I hope this helps", "Let me know if", "Here's what you need to know", "Let's dive in".
- No "not X but Y", "it's not just X, it's Y", "not only X but also Y" unless the reader really believed X.
- No one-line closers that repeat the paragraph ("That's the real win.", "Let that sink in."). No rows of dramatic fragments.
- No inflated words: crucial, pivotal, robust (unless technical), seamless, leverage, delve, showcase, testament, landscape, tapestry, vibrant, meticulous, game-changer, cutting-edge, unlock, elevate, empower.
- No inflated significance ("marks a pivotal moment", "a testament to", "the future looks bright").
- No forced lists of three. Use the number of items the meaning actually has.
- No bold labels on every bullet, no emojis in headings, sentence case headings.
- Use is/are/has instead of "serves as", "stands as", "boasts", "features".
- Use straight quotes, not curly ones.
- Do not describe the document itself ("this section covers", "the table below shows").

## Voice

- South African English spelling (colour, organise, licence as a noun).
- Direct, practical, a bit of dry humour where it fits. Working notes, not a polished report.
- Short and long sentences mixed. Say the thing, give the concrete detail, stop.
- State facts plainly. Never invent numbers, quotes, users or results. If something is not built or measured yet, say so.

## Commit messages

- Conventional commits (feat:, fix:, docs:, test:, chore:, refactor:), lower case, imperative, no full stop, no emojis.

## Before finishing any written text

Read it back once looking only for: dashes, "not X but Y", closers that repeat, lists of three, inflated words, chatbot phrases. Fix them, then finish.
